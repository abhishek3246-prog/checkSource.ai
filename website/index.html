How it works

Three steps. No account required to install.

  1. Install Download the extension and load it in Chrome in under a minute.
  2. Browse Open any site with images — news, social, blogs, search results.
  3. Check Hover an image for a full report, or select text and tap Check text.

What you get

More than a yes/no label — a practical authenticity report.

A clear score for how likely an image looks synthetic versus photographic.

Install in Chrome

  1. Download and unzip checkSource.ai-extension.zip.
  2. Open chrome://extensions in Chrome.
  3. Turn on Developer mode (top right).
  4. Click Load unpacked and select the unzipped folder.
  5. Pin checkSource.ai from the puzzle icon — then hover any image to start.

Chrome Web Store listing coming soon. Until then, Load unpacked is the free public install path.
