How it works

Three steps. No account required to install.

  1. Install Download the extension and load it in Chrome in under a minute.
  2. Browse Open any site with images — news, social, blogs, search results.
  3. Check Hover an image for a full report, or select text and tap Check text.

Install guide

Same Chrome steps on every computer — unzip differs slightly by OS.

  1. Click Download for Chrome and save the zip.
  2. In Finder, double-click the zip (or right-click → Open With → Archive Utility).
  3. Open Chrome and go to chrome://extensions.
  4. Turn on Developer mode (top right).
  5. Click Load unpacked → select the unzipped checkSource.ai folder.
  6. Pin the extension from the puzzle icon, then hover any image.
  1. Click Download for Chrome and save the zip.
  2. In File Explorer, right-click the zip → Extract All… → Extract.
  3. Open Chrome and go to chrome://extensions.
  4. Turn on Developer mode (top right).
  5. Click Load unpacked → select the extracted folder (the one with manifest.json).
  6. Pin the extension from the puzzle icon, then hover any image.

Next steps

Finish setup in Chrome

  1. Unzip the download (Mac: double-click · Windows: Extract All).
  2. Open chrome://extensions and enable Developer mode.
  3. Click Load unpacked and choose the unzipped folder.
  4. When Chrome opens the welcome page, pin checkSource.ai and hover an image.

Works the same on Mac and Windows. No token or account needed.
