You’re almost ready

checkSource.ai is installed. Follow these next steps — same flow on Mac and Windows.

  1. Pin the extension

    Click the puzzle piece icon in Chrome’s toolbar → find checkSource.ai → click the pin.

  2. Open any website with images

    News, social, blogs, Google Images — anything in Chrome.

  3. Hover an image

    A report card appears with AI probability, edit signals, and reverse-search links.

  4. Optional: check text

    Select a sentence on a page → click Check text.

Unzip tip by computer

Mac

Double-click the .zip in Finder, or right-click → Open With → Archive Utility.

Windows

Right-click the .zip → Extract All… → choose a folder → Extract.

Ready out of the box — no setup token required.
